# M8 Brief v0.6 Delta — SIGReg anti-collapse (supersedes v0.5 §1, §5, §7)

**Status:** Durable delta to brief v0.5 (`2026-06-06_m8-brief-v0.5.md`). Supersedes the three named sections; everything else in v0.5 stands unchanged. Written 2026-06-09.

**Decision.** Brian, 2026-06-09: refactor M8's anti-collapse mechanism from **EMA-target + VICReg** to **SIGReg** — the Sketched-Isotropic-Gaussian Regularizer from Balestriero & LeCun's *LeJEPA* (2025), applied in *LeWorldModel* (Maes, Le Lidec, Scieur, LeCun, Balestriero, 2026, arXiv:2603.19312). The method is taken on the authors' results; this delta specifies the integration on the v2 PC living-weight substrate.

**Routing.** Decision: Brian. Plan + this spec: 4.8 (planning/research). Implementation: 4.7. The implementation relay brief was handed to 4.7 on 2026-06-09 (chat relay, not committed); this doc is the durable record it points at.

**Why this supersedes the EMA+VICReg design.** The deepest unresolved unknown in M8 has been whether EMA-target asymmetry resists collapse over a substrate whose weights self-modify at inference ("living weights") — unstudied in the literature (see `2026-06-05_m8-collapse-review.md` §1.5). SIGReg prevents collapse with **no EMA, no stop-gradient, no teacher-student asymmetry** (LeWM §3.1, verbatim: *"We do not employ stop-gradient, exponential moving averages, or additional stabilization heuristics... all parameters are optimized jointly end-to-end"*). It therefore **retires that unknown entirely** — there is no EMA to question. It also reduces six tunable loss hyperparameters to one (λ), and — being an output-distribution regularizer rather than a backbone-asymmetry — it is the kind of mechanism our own collapse review found *most* reliable across substrates (the VICReg pillar acted on output statistics regardless of backbone; SIGReg is the same class, simpler and with provable guarantees). The synthesis of our prior research was "keep the substrate-agnostic pillar, drop the uncertain EMA one"; SIGReg takes that to its conclusion.

## Supersedes §1 — Loss & architecture

**New objective (per modality, summed):**

```
L_total = sum_m [ L_pred(m) + lambda * SIGReg(m) ]    for m in {text, audio, vision}
```

- **`L_pred(m)`** = MSE between the predictor's output and the modality's target-region embedding. **No EMA target** — the target is the **live online encoder's** output for the target region; gradients flow through everything (LeWM is fully end-to-end). (`L_pred` = MSE per LeWM; the L1/MAD rationale from the V-JEPA line is now moot since SIGReg, not the loss form, handles collapse. L1 remains a 4.7 implementation option.)
- **`SIGReg(m)`** = the Gaussian-distributional regularizer, computed per modality on that modality's embeddings.
- **`lambda`** = 0.1 (LeWM default; the *only* tuned hyperparameter).

**SIGReg mechanism (reference impl: `github.com/lucas-maes/le-wm`, `module.py`):**

```python
class SIGReg(torch.nn.Module):
    """Sketch Isotropic Gaussian Regularizer (single-GPU!)"""
    def __init__(self, knots=17, num_proj=1024):
        super().__init__()
        self.num_proj = num_proj
        t = torch.linspace(0, 3, knots, dtype=torch.float32)
        dt = 3 / (knots - 1)
        weights = torch.full((knots,), 2 * dt, dtype=torch.float32)
        weights[[0, -1]] = dt
        window = torch.exp(-t.square() / 2.0)
        self.register_buffer("t", t)
        self.register_buffer("phi", window)
        self.register_buffer("weights", weights * window)

    def forward(self, proj):  # proj: (T, B, D)
        A = torch.randn(proj.size(-1), self.num_proj, device=proj.device)
        A = A.div_(A.norm(p=2, dim=0))
        x_t = (proj @ A).unsqueeze(-1) * self.t
        err = (x_t.cos().mean(-3) - self.phi).square() + x_t.sin().mean(-3).square()
        statistic = (err @ self.weights) * proj.size(-2)
        return statistic.mean()
```

Project the batch of embeddings onto `num_proj=1024` random unit directions; on each 1-D projection compute the **Epps-Pulley** statistic — squared difference between the empirical characteristic function (mean of cos/sin over the batch dimension) and the standard-Gaussian CF (real part `exp(-t^2/2)`, imag 0), integrated over `t in [0,3]` (17 knots, trapezoidal, Gaussian window). By **Cramér-Wold**, matching all 1-D marginals to N(0,1) is equivalent to the joint being isotropic Gaussian. A constant cannot be Gaussian (blocks complete collapse); the isotropic prior forces unit variance + zero covariance (blocks dimensional collapse). LeJEPA states this gives *provable* anti-collapse guarantees.

**Required: a BN projection head before SIGReg.** SIGReg targets N(0,1), so its input must be ~standardized (zero mean, unit variance). A 1-layer MLP + BatchNorm provides this. **Critical:** the trunk's final LayerNorm washes out the distribution SIGReg shapes (LeWM notes this explicitly), so SIGReg must run on a **separate BN-projected head, not the LayerNorm'd trunk output**. The v2 trunk has `final_norm` (LayerNorm) — same gotcha.

**"What is a sample" for SIGReg.** LeWM regularizes one CLS embedding per frame. M8 has per-position latents per modality. Treat each modality's per-position embeddings across the batch as the sample set: feed SIGReg `(T, B, D)` with `B = batch x positions`. Per modality.

**Removed from v0.5 §1:** the EMA target encoder and all of B6 (deepcopy, `update_target_ema`, target-buffer snapshot/freeze, eval/no_grad target forward, constant EMA momentum); VICReg `L_var`/`L_cov`; the L1/MAD justification. The per-modality std-EMA L1 normalizer + epsilon floor (v0.4 F4) is **reconsidered** — likely unnecessary once BN standardizes each modality's embeddings (4.7 to confirm).

**Preserved from v0.5 §1:** the per-modality disjoint 80/20 tail masking; the bidirectional JEPA encoder (`causal=False`); the multimodal per-modality structure (SIGReg per modality carries over the F1/F2 single-modality-collapse protection); the predictor (2-layer transformer); all DO-NOT-REINVENT substrate constants.

## Supersedes §5 — Instrumentation

- **Remove** (no EMA target to compare against): the encoder-asymmetry cosine, the target-encoder per-dim std.
- **Add:** the per-modality **SIGReg loss value** — a direct collapse signal (rising SIGReg = embeddings drifting off-Gaussian).
- **Keep** (now measured on the online output): per-modality per-dim std, mean off-diagonal correlation, singular-value spectrum / effective rank / stable rank, LID; the predictor-trivial cosine (`predicted` vs `target`); substrate-health (`pred_frob`, `err_acc`); the per-modality cadence and pilot-set machinery (commit 72526cb).

## The new open question (replaces the EMA-over-living-weights unknown)

Does the PC top-down sweep pull the representation off-Gaussian between batches, fighting SIGReg's per-batch pull? **The SIGReg loss value is the tell** — if it cannot be driven down on the living-weight substrate, the inference-time plasticity is working against the regularizer. This is plausibly *more tractable* than the EMA question (SIGReg is a hard, direct per-batch constraint on the output distribution, not an indirect dynamical asymmetry), but it is unstudied. The first multimodal smoke is the test, and the SIGReg trajectory is the headline metric to read. This is the v0.5 §10.10 falsifier, reframed for the new mechanism.
