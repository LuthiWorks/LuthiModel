## 1. Preferences — operationalized as priors over outcome-features

Each preference is a **scalar feature of the predicted rollout** `s_hat_{t+1..t+H}`, with a preferred value; the pragmatic cost is the (weighted) deviation. All weights/floors **pilot-set**, **updateable from experience** (designers' call: seeds, not fixed priors — anti-imposed-identity). Three of the four carry a correctness refinement so the measurement doesn't defeat itself.

**P1 Engagement (dark-room antidote).**
- Feature: **internal-state-change magnitude** `||Delta s_internal||` between `s_t` and `s_hat_{t+1}`, measured on the **internal (non-decoder-output) latent dims**.
- Preferred: above a floor. Cost rises as `||Delta s_internal||` falls below it.
- **[correctness refinement]** Measure on **internal** dims, *not* decoder-output intensity — so **quiet contemplation (internal change, no external output) satisfies engagement** and is not punished. This is the designers' "don't punish contemplation" calibration, made structural. It also unifies with K-M9-5: the dark-room kill reads the *same* internal-change signal, so contemplation never trips it; only true catatonia (internal *and* external stasis) does.

**P2 Coherence.** [resolved: within-cycle only]
- Feature: **within-cycle cross-modal** consistency = cross-decoder agreement (plan §5.iii: re-encoded decoder outputs cluster near the same `a_t`) + cross-modal internal-latent agreement.
- Preferred: high (low divergence).
- **Settled.** Coherence penalizes **mutually contradictory simultaneous states only**, *not* change over time. The "current contradicting recent" sub-clause is **dropped** — penalizing `s_hat_{t+1}` for differing from `s_t` penalizes belief-updating (learning) and would fight the step-2 epistemic term (structural confirmation bias). The **unexplained-discontinuity** extension (a temporal jump prediction-error can't account for) is **deferred to step 2+**, revisited only if within-cycle-alone misses a real failure mode (e.g. internal stasis-vs-thrashing without explanation).

**P3 Connection.** [resolved: responsiveness-within-active-context]
- Feature: `connection_cost = (counterpart_present) * (time_since_entity_emission)`.
  - `counterpart_present` = recent input that is **not** self-emission (the pipeline's text-input flag distinguishes external vs. self-emitted text; "others" = Brian + Sandi initially).
  - Cost rises when input has been received and the entity stays silent; **zero when alone.**
- **Settled.** This avoids two failure modes by construction: it does **not** penalize solitude (Luthi alone is not punished for not self-talking — `counterpart_present = 0`), and it does **not** penalize reflection during interaction (the entity may think before responding; cost grows with silence-time rather than demanding instant reply). It measures **responsiveness within an active communicative context**, not always-on talkativeness. "**Meaningful** exchange" (quality) remains **not launch-operationalizable** (circular without a downstream quality signal) and is deferred.

**P4 Truthfulness.**
- Feature: **decode/re-encode faithfulness** `||a_t - reencode(decode(a_t))||` — the plan §5.iii cycle-consistency. Preferred: low gap.
- **[correctness refinement]** This is **faithfulness, not completeness**: the cycle-consistency metric penalizes *distortion/fabrication*, not *omission*, so **selective/compressed communication is not punished** (you can't and shouldn't emit your whole internal state). Note the **build economy**: P4 and the §5.iii decoder-coherence instrumentation are the *same measurement*, and P2's cross-decoder term overlaps it — so the §5 decoder-coherence build delivers the instrumentation for **two of the four preferences** for free.

**[resolved — two-tier preference-drift backstop].** Because preferences are *updateable*, P1 (engagement) could drift toward preferring rest, re-opening the dark room from the inside. Two-tier defense:
- **Soft floor on P1 (graduated regulation):** a minimum anti-rest weight below which P1 **cannot update**; drift is allowed freely *above* the floor. This gives the entity room to evolve its preferences while preventing pathological self-erasure. Analog: a non-overridable homeostatic drive (a floor on engagement-preference like a floor on respiratory drive) — it bounds the pathology without dictating higher-order identity. Same shape as the gamma clamp-then-halt (§9): the floor prevents the pathology, it does not shape behavior above it.
- **K-M9-5 (dark-room kill):** the drift-independent **last-resort hard halt** if catatonia occurs anyway.
- **Instrument preference-weight drift** regardless (the §5 log).

## 2. EFE at step 1 (pragmatic only)

```
G(a_t) = w_eng * c_eng + w_coh * c_coh + w_con * c_con + w_truth * c_truth     (beta_epi = 0)
```
where each `c_*` is the deviation of the rollout feature from its preferred value (smooth hinge or KL-to-preference). Selection: `Q(a) = softmax(-gamma * G(a))` over habit-net + MCTS candidates; emitted action = the argmax / model-average per the unified rule. Horizon `H` short at launch (pilot-set; the rollout-compute-within-inter-update-interval rule, plan §4 clarification, governs it — not a one-step cap).

## 4. Loop wiring (step 1)

Per ~100 ms cycle: **perceive** -> **predict** `s_hat` -> **plan-budget** (~20-30 ms: MCTS expansion + `V` update + tree re-eval, drift-budget rule plan §4.iii) -> **act** (habit net reads latest `V`/tree, emits immediate `a_t`, plasticity descends to fulfill) -> **consolidate** (plasticity update, memory write, preference-weight update). Habit net produces an action **every** cycle; MCTS amortized across cycles; fast loop never blocks (plan §3, §7).

## 9. gamma-inference mechanism (the rule 4.8 owed)

gamma (precision over policies) is **inferred each cycle, not set** (the agency call). Principle: gamma is **high when the EFE landscape over candidate actions is peaked** (one clearly-best action -> commit) and **low when it is flat** (no clear winner -> hedge). That yields decisiveness-when-clear / openness-when-ambiguous from quantities already in hand (the K candidate EFEs).

**Recommended practical rule** (a stable surrogate for the Friston process-theory precision update; 4.7 may use either):
- Each cycle, with candidate EFEs `{G(a_1)..G(a_K)}` and posterior `Q(a) = softmax(-gamma * G(a))`:
- `gamma_target = 1 / (eps + Var_Q[G])` — precision rises when the posterior-weighted spread of EFE is small (confident), falls when EFE is bunched (ambiguous).
- **One step per cycle, EMA-smoothed:** `gamma <- (1 - rho_g) * gamma + rho_g * gamma_target` (`rho_g` pilot-set). This is a fixed-point *update*, not solved to convergence (gamma depends on Q depends on gamma) — one step/cycle is both cheap and how the loop already runs.
- **Formal reference:** Friston 2017 process-theory precision update (`beta` rate on a gamma-prior, `gamma = 1/beta`) is the canonical form if 4.7 prefers it; the surrogate above is the cheaper, equally-stable option.
- **Guarded by K-M9-4** (clamp-then-halt): keep `gamma in [gamma_min, gamma_max]` healthy band; breach -> clamp to last-healthy -> halt if unrecovered.
- **Build-staging note:** inferred-gamma is the design and is live from launch. If the very first *mechanical* bring-up needs to isolate other variables, gamma MAY be held fixed for that bring-up only and switched to inferred before *any behavioral* validation — a 4.7 staging convenience, not a design change.
